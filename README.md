# Paradigma-opdracht

Deze repository is gemaakt voor de paradigma-opdracht van de course APP.

Voor deze opdracht heb ik een JSON-parser ontwikkeld in Haskell. 

## Uitvoeren

Voor dit project zijn GHC en Cabal nodig.

Open een terminal in de hoofdmap van het project en voer uit:

```bash
cabal build
cabal run
```

Na het uitvoeren vraagt het programma om een JSON-waarde.
De parser toont vervolgens het resultaat of een foutmelding.
